# Документация проекта

## Описание технологий и синтаксиса
Проект использует следующие технологии и подходы к разработке:
* **Python**: Основной язык программирования для написания автотестов.
* **Selenium**: Библиотека для автоматизации действий пользователя в веб-браузере.
* **Pytest**: Фреймворк для написания и запуска тестов.
* **Allure**: Инструмент для генерации интерактивных и наглядных отчетов о выполнении тестов.

## Форматирование кода
* **PEP 8**: Весь исходный код строго форматируется в соответствии со стандартным стилем написания кода на Python.
* **Docstrings**: Используется для документирования методов и функций.
* **Разметка шагов**: Все ключевые действия внутри тестов размечаются с помощью контекстного менеджера `with allure.step` или декоратора `@allure.step` для детального отображения в отчетах.

## Инструкция по запуску тестов для формирования отчета

### 1. Установка зависимостей
Перед началом работы убедитесь, что установлены все библиотеки проекта:
```bash
pip install -r requirements.txt
```

### 2. Запуск автотестов
Для выполнения тестовых сценариев выполните следующую команду в корневой директории:
```bash
pytest --alluredir=./allure-results
```
*Эта команда запустит тест (включая авторизацию, добавление 3-х товаров в корзину и заполнение персональных данных покупателя) и сохранит результаты в директорию `./allure-results`.*

## Инструкция по просмотру сформированного отчета Allure

### 1. Запуск локального сервера отчетов
После завершения теста, чтобы просмотреть отчет, выполните команду:
```bash
allure serve ./allure-results
```
*Эта команда запустит локальный сервер и откроет отчет в браузере.*

### 2. Структура отчета в интерфейсе Allure
В итоговом отчете для теста `test_shop` вам будут доступны:
* **Характеристики теста**: Корректное название сценария (*"Успешное оформление заказа на покупку нескольких товаров в магазине"*), уровень критичности (*critical*) и развернутое описание проверяемого бизнес-процесса.
* **Дерево шагов**: Вы увидите пошаговое выполнение сценария:
  1. Открыть сайт магазина
  2. Выполнить авторизацию под стандартным пользователем
  3. Нажать кнопку входа 'Login'
  4. Добавить товары в корзину
  5. Перейти в корзину
  6. Проверить содержимое корзины на наличие добавленных товаров
  7. Нажать на кнопку 'Checkout' для перехода к оформлению
  8. Заполнить форму персональными данными покупателя
  9. Нажать кнопку 'Continue' для перехода к деталям заказа
  10. Проверить итоговую стоимость заказа (Total)
* **Результаты выполнения**: Статус прохождения (Passed/Failed). В случае падения (например, несовпадения итоговой цены) будет выведена ошибка с ожидаемым и фактическим результатом.
